🚌 Bus Station Ticket Counter System

📌 Short Description

A simple and interactive Bus Ticket Counter web application built using HTML, CSS, and JavaScript. This project calculates ticket eligibility and discounts based on age and gender, providing a dynamic and user-friendly experience with popup-based results.



📖 Project Overview

The Bus Station Ticket Counter System is a front-end web application designed to simulate a real-world bus ticket eligibility system. Users can enter their name, age, and gender to check whether they qualify for a free ride, discounted ticket, or full ticket.

This project demonstrates core JavaScript concepts including:

• Conditional Statements (if-else)

• Form Handling

• DOM Manipulation

• Event Listeners

• Dynamic Content Rendering

The interface is clean, responsive, and enhanced with smooth animations for a better user experience.



🚀 Features

• 🧾 User input form (Name, Age, Gender)

• 🎯 Age-based ticket calculation

• 👨 Male ticket policy logic

• 👩 Female special discount logic

• 🎉 Free ride eligibility for young children

• 👴 Senior citizen discount

• 💬 Popup result display with animation

• 🎨 Modern UI with gradient background

• ⚡ Smooth hover effects and transitions



🛠️ Technologies Used

• HTML5 – Structure of the application

• CSS3 – Styling and animations

• JavaScript (ES6) – Business logic and interactivity

🧠 Ticket Logic Summary


👨 For Male:

• Age ≤ 5 → Free Ride

• Age 6–8 → 50% Discount

• Age 9–65 → Full Ticket

• Age > 65 → 30% Senior Citizen Discount


👩 For Female:

• Age ≤ 5 → Free Ride

• Age 6–8 → 50% Discount

• Age ≥ 9 → 50% Special Discount
